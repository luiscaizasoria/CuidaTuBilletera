# Architecture Rules

## Objetivo

Mantener la arquitectura definida del proyecto ControlGastos.

## Reglas obligatorias

- Consultar docs/001-CONSTITUCION.md antes de modificar arquitectura.
- No crear componentes fuera de la estructura definida sin justificación.
- La API mantiene las reglas de negocio.
- Las decisiones arquitectónicas relevantes deben documentarse.
- Evitar complejidad innecesaria.
