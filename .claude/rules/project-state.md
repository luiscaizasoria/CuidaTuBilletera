# Project State Rules

## Objetivo

Mantener el estado del proyecto sincronizado mediante documentación.

## Reglas obligatorias

- Consultar docs/004-ROADMAP-PROYECTO.md antes de iniciar tareas.
- Actualizar el Roadmap únicamente después de validar resultados.
- No marcar actividades completadas sin evidencia.
- Mantener alineados código, documentación y estado del proyecto.
- Los cambios de fase deben quedar reflejados en la documentación correspondiente.
